# 상담기록관리 XLSB 가져오기

설정 → DB → **울산형 상담기록관리 DB 가져오기**에서 사용합니다.

1. 인적사항의 학년도를 지정하고 **교시별 시작 시간 설정**에서 한국 시간 기준 시작 시각을 입력합니다. 유효한 시간은 현재 암호화 DB에 자동 저장되어 화면이나 앱을 다시 열어도 사용합니다.
2. `인적사항등록`, `상담대장` 시트를 포함한 `.xlsb` 파일을 업로드합니다. 파일에 추가 교시가 있으면 설정 창에도 추가됩니다.
3. 검사 결과를 확인합니다. 오류가 있으면 **행 수정 / 일지 지정 / 제외**에서 오류가 있는 시트와 행만 선택할 수 있습니다. 값을 수정하고 **수정사항 저장 후 다음 오류**를 누릅니다. 오류가 모두 해결되어야 저장할 수 있습니다.
4. **검사한 자료를 DB에 추가**를 누르면 현재 DB에 저장됩니다. **업로드 취소**는 파일과 이번 수정·제외 내역, 검사 결과를 초기화합니다. 교시 시간은 유지됩니다.

수정은 이번 이관에만 적용하며 원본 파일은 바꾸지 않습니다. 한 행씩 저장 후 전체를 재검사하며 편집 창을 유지합니다. 해결된 행은 목록에서 빠지고 다음 오류 행을 표시합니다. 오류가 남으면 같은 행을 다시 수정할 수 있습니다. 모든 오류가 해결되면 완료 안내를 표시하며, 창을 닫고 DB 추가를 진행합니다. 인적사항 행을 제외하면 해당 사례에 연결된 일지도 수정하거나 제외해야 합니다. 제외한 행은 검사 결과의 **제외한 행 모두 복원 후 다시 검사** 버튼으로 복원할 수 있습니다. 이미 가져온 파일은 일부 행을 제외했더라도 재등록이 차단되므로 제외 내역을 저장 전에 확인하세요.

오류 수정 화면의 일자·상담일자·생년월일은 `YYYY-MM-DD` 형식으로 표시합니다. 날짜로 해석할 수 없는 값은 원문을 표시하므로 직접 수정하세요. 값을 변경하지 않으면 원본 Excel 날짜 값은 유지됩니다.

## 일지 분류

| 원본 조건 | 등록할 일지 |
| --- | --- |
| 대분류가 교육·연구·의뢰 | 자동 분류하지 않고 행별 오류 표시. 사용자가 개인 상담·집단 상담·교사 자문·심리검사·교육/행사·특별교육 중 선택 |
| 대분류 검사 + 중분류 심리검사 + 상담구분 집단심리검사 | 교육/행사의 **단체심리검사** |
| 상담구분 개인심리검사 | 학생에 연결된 심리검사 (자문 분류보다 우선) |
| 대분류 자문 또는 교원자문 | 교사 자문 |
| 그 외 | 학생이면 개인 상담, 집단이면 집단 상담 |

특별교육을 선택하면 근거 법률(학교폭력예방법·교원지위법)을 함께 선택해야 합니다. 학생 인적사항에 연결하며, 같은 사례번호와 근거 법률의 일지는 하나의 신규 특별교육에 묶어 저장합니다. 검사 결과에도 특별교육으로 표시합니다.

직접 선택한 일지가 자동 규칙보다 우선합니다. 개인 상담과 심리검사는 학생, 집단 상담은 집단 인적사항이 필요합니다. 교육/행사는 인적사항 연결 없이도 등록할 수 있습니다. 수동 지정한 교육/행사는 기본 분류가 교육이며, 상담구분이 집단심리검사이면 단체심리검사로 저장합니다.

교사 자문은 인적사항의 성명/집단명을 교사 이름, 학생연락처를 교사 연락처로 사용합니다. **상담구분을 자문분야로 저장**합니다. 가능한 값은 학교학습·사회성발달·정서발달·진로발달·행동발달·기타이며 다른 값은 화면에서 수정하도록 오류를 표시합니다. 같은 사례번호에 교사 자문과 학생/집단 상담이 섞이면 사례번호와 인적사항을 수정해야 합니다.

개인 상담의 상담 분야는 원본 **상담구분**, 상담 유형은 원본 **중분류**에서 가져옵니다. 중분류가 비어 있으면 상담 유형은 개인상담으로 저장합니다.

개인 상담의 중분류가 학부모상담이면 대상은 보호자(가족), 분야는 상담구분의 학생관련상담·교사관련상담·학습·기타를 사용합니다. 그 외 분야는 기타로 저장합니다. 개인심리검사의 원본 대상이 학부모·보호자·보호자(가족)·보호자(학부모)이면 보호자(학부모), 나머지는 학생으로 저장합니다.

## 필드와 시간

- **본문에는 상담내용만**, 학생/집단 **비고에는 원본 비고만** 넣습니다. 원본 행 전체나 인적사항을 본문·비고에 덧붙이지 않습니다. 대응 필드가 없는 원본 열도 덧붙이지 않습니다.
- 학생의 학년·반·생년월일·연락처와 지정 학년도 학적을 등록합니다. 학생 번호나 집단 구성원을 추정하지 않습니다.
- 울산형 원본에 없는 집단상담 출석 정보는 이관하지 않으며, 가져온 일지의 출석 목록은 비워 둡니다.
- 일자(없으면 상담일자)는 Excel 날짜 숫자 또는 YYYY-MM-DD를 사용합니다.
- 교시는 `1`, `01`, `1교시`를 동일하게 처리하며 점심 등 이름도 지원합니다. 시작 시간이 없으면 오류로 표시합니다.
- 소요 시간은 시간(시) × 60 + 시간(분)입니다. 음수는 허용하지 않으며 합계는 1~1440분의 정수여야 합니다.
- 원본 상담자성명은 일지 작성자로 보존합니다. 교육/행사는 날짜·시각·시간·대상·인원·진행자·제목·내용을 옮깁니다.

## 검증과 제한

- 오류 표에서 시트·원본 행·오류 내용을 확인하고 등록 대상 표에서 변환 결과를 확인합니다.
- 식별 정보가 호환되는 기존 학생·교사·집단은 연결합니다. 후보가 여러 명이거나 정보가 충돌하면 오류로 표시하므로 화면에서 원본 정보를 바로잡거나 해당 행을 제외하세요.
- 수정·분류·시간 설정과 무관하게 원본 자료 기준으로 재등록을 차단합니다.
- 검사에서는 이관 자료를 쓰지 않습니다. 교시 설정은 별도로 저장합니다. 저장 직전 다시 검사하고 인적사항·일지·이관 이력을 한 트랜잭션으로 저장하며 실패하면 전체 취소됩니다.
- 10MB 이하, 압축 해제 80MB 이하, 시트당 20,000행/100열까지 읽습니다.
- 매크로·수식을 실행하지 않고 저장된 셀 값을 읽습니다. Excel에서 계산·저장한 파일을 사용하세요. 숫자로 저장되어 사라진 연락처의 앞자리 0은 추정하지 않습니다.

테스트는 가상 자료와 임시 암호화 DB를 사용합니다.
