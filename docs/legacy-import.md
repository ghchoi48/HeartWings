# 상담기록관리 XLSB 가져오기

설정 → DB → **기존 상담기록관리 DB 가져오기**에서 사용합니다.

1. 인적사항의 학년도를 지정하고 **교시별 시작 시간 설정** 창에서 각 교시의 시작 시각(한국 시간)을 입력합니다.
2. `.xlsb` 파일을 업로드합니다. `인적사항등록`, `상담대장` 시트를 모두 포함해야 합니다.
3. 파일에 추가 교시가 있으면 설정 창에 자동으로 추가됩니다. 시작 시간을 입력하고 **설정 적용 후 다시 검사**를 눌러 인원·건수·시작 시각·소요 시간과 행별 오류를 확인합니다.
4. **검사한 자료를 DB에 추가**를 누르면 현재 열린 암호화 DB에 저장됩니다.

옵션을 바꾸면 검사가 취소됩니다. **설정 적용 후 다시 검사**로 업로드한 파일을 다시 검증하세요.
원본 파일과 기존 DB 자료는 수정하지 않습니다. 필요하면 같은 화면의 DB 백업 다운로드로 사본을 보관할 수 있습니다.

검사 결과 상단에 학생·교사·집단·상담·교사 자문·오류 건수를 표시합니다. 아래의 **검사 오류**, **인적사항 등록 대상**, **상담·자문 등록 대상** 표에서 전체 결과를 10건씩 확인하고 열 제목을 눌러 정렬할 수 있습니다. 오류 표에는 시트·원본 행·확인할 내용을, 상담 표에는 저장 유형·대상·시작 시각·소요 시간·제목·원본 상담자를 표시합니다.

## 원본 구조와 변환

제공된 파일은 인적사항등록 6행, 상담대장 4행에 제목이 있는 빈 서식입니다.
접수번호, 1900 학년도, 0 상담일자 등 빈 서식의 계산 결과는 상담으로 등록하지 않습니다.
제목 행은 처음 20행에서 자동 탐색하며 공백·줄바꿈을 무시합니다.

| 원본 | 프로그램 DB |
| --- | --- |
| 사례번호 | 개인/집단과 상담 기록 연결 키, 원본 메모에 보존 |
| 성명/집단명, 성별/인원 | 남·여·기타이면 학생, 양의 정수 인원이면 집단 |
| 대분류 = 자문 | 연결된 인적사항을 교사로 등록하고 상담 행을 교사 자문 일지로 저장 (성별/학년/반 불필요) |
| 상담 구분 = 개인심리검사 | 학생에 연결된 심리검사 일지로 저장 (자문 분기보다 우선) |
| 중분류 = 학부모상담 (개인 상담) | 상담 대상은 보호자(가족), 상담 분야는 원본 상담 구분에 따라 저장 |
| 학년, 반, 생년월일, 학생/보호자 연락처 | 학생 기본 정보 및 지정 학년도 학적 |
| 소속학교, 비고 및 원본 인적사항 열 | 학생/집단 메모 |
| 일자 (없으면 상담일자) | 상담 날짜, Excel 날짜 숫자와 YYYY-MM-DD 지원 |
| 교시 | 해당 교시에 설정한 시작 시각 |
| 시간(시), 시간(분) | 시간(시) × 60 + 시간(분)을 소요 시간(분)으로 저장 |
| 상담 제목, 상담 내용 | 개인/집단 상담 일지 (완료 상태) |
| 상담 구분, 매체, 대상, 중분류/대분류 | 개인 상담 분류·방법·대상·영역 |
| 상담자 성명 | 원본 작성자, 빈 값이면 등록 당시 교사 |
| 원본 상담 열 전체 | 상담 본문 하단에 텍스트로 보존 |

원본은 학생 번호 열이 없어 번호를 생성하지 않습니다. 집단 명단은 원본 인원만 보존하며 학생 구성원을 추정하지 않습니다.
`교시`는 숫자 `1`, 문자열 `01`, `1교시`를 동일하게 인식합니다. 기본 입력창은 1~7교시이며, 0교시·8교시·점심 등 파일에서 발견한 다른 값도 설정할 수 있습니다. 시작 시간을 임의로 추정하지 않으므로 원본 교시가 비어 있거나 해당 시작 시간을 설정하지 않으면 행별 오류로 보고합니다.
소요 시간은 예를 들어 `시간(시)=1`, `시간(분)=30`이면 90분입니다. 한쪽이 비어 있으면 0으로 계산합니다. 두 값은 음수가 아닌 숫자여야 하며 합계는 1~1440분의 정수여야 합니다. 두 칸이 모두 비었거나 합계가 0이면 저장하지 않습니다. 개인·집단 상담에 같은 규칙을 적용하며 원본 시간 값도 본문에 보존합니다.
인적사항에 학년도 열이 없어 사용자가 지정한 학년도로 저장합니다. 상담대장의 학년도는 원문에 보존하며 과거 학적을 추정하지 않습니다.
원본에 대응하는 독립 필드가 없는 항목은 메모/본문에서 확인할 수 있습니다.

### 교사 자문

대분류의 앞뒤 공백을 제거한 값이 `자문`이면 교사 자문으로 등록합니다. 사례번호로 연결된 인적사항의 `성명/집단명`이 **자문 대상 교사 이름**이며, 원본 `상담자 성명`은 **일지 작성자**입니다. 인적사항의 `학생 연락처`는 교사 연락처로 옮기고 원본 인적사항 전체는 자문 본문 하단에 보존합니다. 같은 사례의 자문 여러 건은 한 교사에 연결됩니다.

중분류가 프로그램의 자문 영역(학교학습·사회성발달·정서발달·진로발달·행동발달·기타)에 해당하면 자문 영역으로 저장합니다. 그 외 값은 영역을 비워 두고 원문에 보존합니다. 교시·시간 환산 규칙은 교사 자문에도 동일합니다. 한 사례번호에 자문과 일반 상담이 섞인 경우에는 대상 혼동을 막기 위해 오류로 보고하므로 원본에서 사례번호를 분리하세요.

### 개인심리검사와 학부모상담

`상담 구분`이 `개인심리검사`이면 심리검사 일지로 저장합니다. 원본 날짜, 교시별 시작 시각, 환산한 소요 시간, 제목, 본문, 상담자 이름을 보존합니다. 학생 인적사항에 연결되어야 하며 집단에 연결된 개인검사는 오류로 보고합니다. 이 분기는 대분류가 자문인 경우에도 우선합니다. 원본 대상이 학부모·보호자·보호자(가족)·보호자(학부모)이면 검사 대상을 `보호자(학부모)`로, 나머지는 `학생`으로 저장하고 원본 대상도 본문에 보존합니다. 개인 상담과 심리검사가 같은 학생 사례에 함께 있어도 각각 해당 일지로 저장합니다.

개인 상담으로 저장하는 행의 `중분류`가 `학부모상담`이면 상담 대상을 `보호자(가족)`으로 변경합니다. 상담 분야는 원본 `상담 구분`이 `학생관련상담`, `교사관련상담`, `학습`, `기타` 중 하나이면 그대로 사용하고, 그 외에는 `기타`로 저장합니다. 원본 상담 구분은 상담 유형과 본문에 보존합니다.

개인 상담 에디터에서도 `보호자(가족)`을 선택하면 상담 분야 옵션이 위 네 가지로 바뀝니다. 다른 상담 대상으로 변경하면 일반 상담 분야 목록으로 돌아옵니다. 대상 변경 후 유효하지 않은 분야는 선택을 해제하며, 두 목록에 공통으로 있는 `기타`는 유지합니다. 기존 보호자 일지의 분야가 새 목록에 없으면 기존 값을 안내하고 다시 선택하도록 표시합니다.

검사 결과 표에는 심리검사 유형과 검사 시각도 표시하며, 상담/검사 대상과 상담 분야 열에서 변환 결과를 확인할 수 있습니다.

## 검증과 제한

- 실제 자료가 없는 서식, 중복 사례번호, 연결되지 않는 상담, 이름 불일치, 잘못된 날짜·필수값은 행 번호와 함께 보고합니다.
- 이름·학년도·학년·반이 같은 학생 또는 이름이 같은 교사/집단은 자동 병합하지 않고 전체 이관을 중단합니다. 동명이인도 확인이 필요합니다.
- 동일한 파싱 자료는 DB의 이관 이력으로 재등록을 차단합니다. 기존 자료에 대한 증분 갱신/병합 기능은 아닙니다.
- 미리보기에서는 DB에 쓰지 않습니다. 저장 직전 중복을 재검사하고 학생·학적·사례·집단·상담·교사·자문·이관 이력을 한 트랜잭션으로 저장합니다. 실패하면 전체 취소됩니다.
- 10MB 이하, 압축 해제 80MB 이하, 시트당 20,000행/100열까지 읽습니다.
- 매크로와 수식은 실행하지 않습니다. 수식은 Excel에 마지막 저장된 결과를 읽으므로 Excel에서 계산 후 저장한 파일을 사용하세요.
- 연락처는 텍스트 저장을 권장합니다. 숫자로 저장되어 이미 사라진 앞자리 0은 추측해 복원하지 않습니다.

실제 개인정보가 담긴 원본과 사용자 DB는 테스트 자료에 포함하지 않습니다. 테스트는 가상 개인·집단 자료와 임시 SQLCipher DB를 사용합니다.
