# 마음나래 · HeartWings

**학교 상담의 기록부터 일정과 통계까지, 한곳에서 관리하는 상담 업무 도구입니다.**

마음나래는 전문상담교사의 학교 상담 업무를 돕는 Python 기반 데스크톱 애플리케이션입니다. 학생별 상담 이력, 집단 상담, 교사 자문, 심리검사 등 다양한 기록을 모으고, 캘린더와 통계로 상담 활동을 살펴볼 수 있습니다. 상담 데이터는 사용자의 컴퓨터에 SQLCipher로 암호화하여 저장합니다.

프로그램 관련 문의는 ghchoi48@aiep.gbe.kr로 메일을 보내주시거나 본 Github 저장소의 Issues 탭을 이용해주시기 바랍니다.

[시작하기](#시작하기) · [주요 기능](#주요-기능) · [빌드 안내](#빌드)

## 시작하기

### 소스에서 실행

저장소를 내려받고 프로젝트 폴더에서 가상환경을 만듭니다. 기존 실행 검증 환경은 **macOS Apple Silicon, Python 3.14**이며, OS별 준비 사항은 [빌드 안내](#빌드)를 참고하세요.

```bash
git clone https://github.com/ghchoi48/HeartWings.git
cd HeartWings
python -m venv .venv
```

가상환경을 활성화합니다.

```bash
# macOS / Linux
source .venv/bin/activate
```

```powershell
# Windows PowerShell
.venv\Scripts\Activate.ps1
```

의존성을 설치하고 앱을 실행합니다.

```bash
python -m pip install -r requirements/desktop.txt
python main.py
```

`python` 명령을 찾을 수 없는 macOS/Linux 환경에서는 가상환경 생성 시 `python3`를 사용하세요.

SQLCipher 드라이버 설치에는 OS·Python·CPU에 맞는 wheel이 필요합니다. wheel이 없으면 SQLCipher와 네이티브 컴파일 환경을 준비해야 합니다. Windows 데스크톱 실행에는 WebView2 Runtime, Linux에는 GTK/WebKit 관련 패키지가 필요합니다.

### 처음 실행할 때

1. 첫 화면에서 사용할 **4글자 이상의 DB 비밀번호와 학교 정보**를 입력합니다.
2. 학생을 등록하거나 XLSX 명부를 가져옵니다. 기존 상담기록관리 자료는 설정의 기존 자료 가져오기 기능으로 가져올 수 있습니다.
3. 상담 일지를 작성하고 캘린더와 통계에서 기록을 확인합니다.
4. **설정 → DB**에서 암호화 백업을 내려받을 수 있습니다.

### 실행 옵션

기본 실행은 데스크톱 창입니다. 브라우저에서 열거나 별도의 DB 파일을 지정할 수도 있습니다.

```bash
# 브라우저 모드: http://127.0.0.1:8080
python main.py --browser --port 8080

# 별도의 DB 파일 사용
python main.py --db ./data/maeumnarae.db
```

두 모드 모두 로컬 주소 `127.0.0.1`에서 실행됩니다. DB는 앱을 처음 열 때 초기화되며, 명령행에서 초기화하거나 열기를 확인하려면 `python init_db.py`를 사용할 수 있습니다.

## 데이터 저장 방식

학생·상담 기록과 첨부파일은 로컬 암호화 DB에 저장합니다. 기본 DB 위치는 다음과 같습니다.

| 운영체제 | 기본 위치                                                                               |
| -------- | --------------------------------------------------------------------------------------- |
| macOS    | `~/Library/Application Support/maeumnarae/data/maeumnarae.db`                           |
| Windows  | `%LOCALAPPDATA%\maeumnarae\data\maeumnarae.db`                                          |
| Linux    | `~/.local/share/maeumnarae/data/maeumnarae.db` (`XDG_DATA_HOME` 설정 시 해당 경로 사용) |

비밀번호는 최소 4글자입니다. 업로드 파일은 서버 측 크기 제한 아래 메모리에서 처리하며 평문 임시파일로 저장하지 않습니다. 첨부파일은 파일당 20MB, 한 번에 10개까지, 명부·XLSB 이관 파일은 10MB, DB 복원 파일은 256MB까지 지원합니다. 동시에 한 업로드 요청만 처리합니다.

급식·날씨·학교 정보 조회와 새 버전 확인에는 인터넷 연결을 사용합니다. 앱 실행 파일과 사용자 데이터는 별도 위치에 보관되며, DB 백업은 **설정 → DB**에서 관리합니다.

**설정 → 일반 → 나이스 연동**에서 NEIS API 인증키와 학교 코드를 저장한 뒤, **캘린더 목록 → 학사일정 (NEIS)**을 체크하면 학교의 학사일정을 월간·주간 캘린더와 홈 캘린더에서 확인할 수 있습니다. 기본적으로 표시가 꺼져 있으며, 선택 여부는 DB에 저장됩니다. 일정은 읽기 전용으로 제공하고 새로고침으로 다시 조회합니다. 인증키 입력란 아래의 **인증키 용도 및 발급 방법**을 펼치면 [나이스 인증키 신청](https://open.neis.go.kr/portal/guide/actKeyPage.do) 안내를 볼 수 있습니다.

## 빌드

주요 기술은 **Python, NiceGUI, pywebview, SQLCipher**이며, 독립 실행 앱 패키징에는 **PyInstaller**를 사용합니다.

```text
HeartWings/
├── main.py              # 앱 실행
├── init_db.py           # DB 초기화·열기 확인
├── maeumnarae/
│   ├── core/            # DB, 모델, 설정 및 공통 기반
│   ├── repositories/    # 데이터 조회·저장
│   ├── services/        # 외부 연동, 가져오기·내보내기, 백업
│   ├── views/           # 화면 구성
│   └── widgets/         # 홈 위젯
├── resources/           # 아이콘, 글꼴, 서식 및 라이선스
├── requirements/        # 실행·빌드 의존성
├── packaging/           # 번들 설정
└── scripts/             # 앱·리소스 빌드 도구
```

대상 운영체제와 CPU에 맞는 Python 환경에서 빌드합니다.

```bash
python -m pip install -r requirements/build.txt
python scripts/build_desktop.py
```

- **Windows:** x64 Python(Tcl/Tk 포함), Inno Setup 6.3 이상이 필요합니다. `ISCC.exe`를 PATH에 추가하거나 `ISCC_PATH`에 전체 경로를 지정할 수 있습니다. 설치 프로그램은 WebView2 Runtime이 없으면 다운로드하여 설치합니다.
- **macOS:** 대상 CPU의 macOS에서 빌드합니다. 배포 시 필요한 서명·공증은 별도로 진행합니다.

Windows 설치 파일은 `dist/installer/maeumnarae-<버전>-windows-x64-setup.exe`, macOS 산출물은 `dist/마음나래.app` 및 ZIP입니다.

아이콘과 시작 화면은 저장소에 포함되어 있습니다. 이미지를 변경할 때는 `scripts/build_icons.py`, `scripts/build_splash.py`로 재생성할 수 있습니다. 글꼴 변환 절차와 라이선스는 `resources/fonts/`와 `resources/licenses/`에 있습니다.

## 로컬 AI (설정 → AI)

AI 탭에서 전체 AI 사용을 켜고 모델을 다운로드하거나 로컬 GGUF 파일을 등록한 뒤,
사용할 모델을 선택하여 한국어 테스트 생성을 실행할 수 있습니다. 최초에는 꺼져 있고,
모델을 자동 다운로드하지 않습니다. 작업 양식 탭에서는 가상 메모로 상담 요약·일지 초안을 시험할 수 있습니다.
실제 상담 일지의 조회·저장·편집기 반영은 아직 연결하지 않습니다.

- **추천 모델:** Qwen3 4B Q4_K_M (약 2.50GB 다운로드, 16GB 메모리 환경 목표).
- **지원:** Windows x64 CPU, Apple Silicon Mac Metal/CPU. 실제 메모리 사용량은 환경에 따라 달라집니다.
- **기존 설치·로컬 등록 EXAONE 이용 조건:** [EXAONE AI Model License Agreement 1.2 - NC](https://huggingface.co/LGAI-EXAONE/EXAONE-4.0-1.2B-GGUF/blob/162446400ea4596377a3ce1d3ddffa32971af0a6/LICENSE)는 비상업적 연구·교육 목적으로 사용을 제한합니다. 일반 상담 실무 이용 허용을 의미하지 않습니다.

모델은 첫 생성 시 로드합니다. AI를 끄면 생성·다운로드를 취소하고 엔진을 종료하지만,
설치한 모델과 선택은 보존합니다. 모델 변경·DB 잠금·앱 종료 때도 엔진을 종료합니다.
모델 준비 후 추론은 인터넷 없이 동작하며 입력·응답을 파일이나 로그에 저장하지 않습니다.
테스트에는 학생 정보나 실제 상담 기록을 입력하지 마세요.

AI 설정과 모델 목록은 현재 DB 폴더의 `ai-settings.json`, `ai-models.json`에,
다운로드한 모델은 `ai-models/`에 보관합니다. 이 파일들은 DB 백업에 포함되지 않습니다.
로컬 GGUF 등록은 원본 경로만 보관하며 등록 해제 시 원본을 삭제하지 않습니다.
로컬 등록은 EXAONE·Qwen2/3·Llama·Gemma 1/2·Phi3 계열의 채팅 템플릿이 있는
단일 GGUF를 지원합니다. 분할 GGUF·멀티모달 모델은 지원하지 않습니다. 파일을 옮기면 다시 등록하세요.

### AI 작업 양식(하네스)

설정 → AI → **작업 양식**에서 다음 순서로 자신만의 양식을 만듭니다.

1. **상담 메모 요약** 또는 **상담일지 초안**을 선택하고 **복제**합니다.
2. 이름·작성 지침·문체를 수정하고 출력 항목을 추가하거나 순서를 바꿉니다. 항목은 1~8개이며 각 항목에 작성 지침과 원문 근거 확인 여부를 지정합니다.
3. 가상 예시를 선택하거나 임시 메모를 입력하고 **시험 실행**을 누릅니다. 저장 전 변경도 시험할 수 있습니다.
4. 항목별 결과와 근거, 검토 알림을 확인한 뒤 양식을 **저장**합니다.

고급 설정에서 JSON을 편집한 뒤 **JSON 변경 적용**을 누르면 쉬운 편집기에 반영됩니다.
**내보내기**는 양식 정의만 JSON 파일로 내려받습니다. **가져오기**는 JSON 파일 업로드 또는
붙여넣기 → 미리 보기 → 새 양식으로 추가 순서이며 기존 양식을 덮어쓰지 않습니다.
실행 코드, 외부 도구 호출, DB 접근을 설정에 넣을 수 없습니다.

사용자 양식은 현재 DB 폴더의 `ai-harnesses.json`에 저장되며 DB 백업에 포함되지 않습니다.
양식 지침에는 학생 개인정보를 넣지 마세요. 시험 입력·결과는 저장·내보내지 않으며,
화면 종료·연결 해제·DB 잠금 때 지워집니다. 기본 양식은 수정할 수 없으며 복제해서 사용합니다.
손상된 양식 파일은 보존하고 오류를 표시하며 기본 양식과 일반 채팅은 계속 사용할 수 있습니다.

시험은 추론 모드를 끄고 최대 1,024토큰으로 생성합니다. 실제 모델의 채팅 템플릿과 토크나이저로
4,096토큰 컨텍스트 예산을 검사하며, 초과한 입력을 자동으로 자르지 않습니다.
형식 오류만 한 번 재시도하고, 취소·시간 초과·출력 잘림은 자동 재시도하지 않습니다.
**형식 검사 통과는 사실성 보장이 아닙니다.** 근거 인용이 원문과 일치하더라도 주장과 근거의 의미가
맞는지는 직접 검토해야 합니다. 특히 작은 모델은 학생 진술과 상담자의 개입을 혼동할 수 있습니다.

소스 실행 전 지원 플랫폼의 엔진을 준비합니다. 배포 앱에는 엔진이 포함됩니다.

```bash
python scripts/prepare_ai_engine.py
python scripts/prepare_ai_engine.py --verify
python main.py
```

모델 다운로드는 공식 revision과 SHA-256을 고정하여 검증합니다. 실패·취소 후 재시도는
처음부터 수행합니다. AI 설정 파일이 손상되면 오류를 표시하며, 손상된 설정을 임의로
덮어쓰지 않습니다. 파일을 확인하거나 별도 보관 후 앱을 다시 실행하세요.

사용할 모델 카드의 **추론 모드**는 EXAONE 4와 Qwen3에서 지원하며 기본값은 꺼짐입니다.
설정은 저장되고 다음 메시지부터 적용됩니다. 추론 모드에서는 생각하는 시간을 포함해
응답이 더 오래 걸릴 수 있으며, 생성 한도는 추론과 답변을 합쳐 2,048토큰입니다.
