# Inno Setup 한국어 번역

`Korean.isl`은 Inno Setup 6.7.3 배포본의 `Languages/Korean.isl`에서 가져온
6.5.0 이상용 번역입니다. 6.5 이상 컴파일러에서 사용합니다.
`Korean-6.3.isl`은 기존 Inno Setup 공식 저장소의 `is-6_3_0` 태그 원본이며,
6.3~6.4 컴파일러에서 사용합니다.
번역자 정보는 파일 머리말에 보존했습니다.

- 현재 번역 원본: https://github.com/jrsoftware/issrc/blob/is-6_7_3/Files/Languages/Korean.isl
- 이전 번역 원본: https://github.com/jrsoftware/issrc/blob/is-6_3_0/Files/Languages/Korean.isl
- 프로젝트 라이선스: https://github.com/jrsoftware/issrc/blob/is-6_3_0/license.txt
- 라이선스 사본: [LICENSE-Inno-Setup.txt](LICENSE-Inno-Setup.txt)

빌드 환경에 한국어 언어 파일이 설치되어 있는지와 무관하게 동일한 번역을 사용합니다.
