- macOS 27.2 / arm64, Python 3.14 계열 (정확한 버전은 릴리스 JSON 참조)

- 시스템 패키지를 참조하는 별도 가상환경에 수정 pyxlsb만 설치
- 수정 버전: `1.0.10+heartwings.validation`
- 수정 내용: 버전 표기 및 날짜 변환 호출을 계수하는 래퍼; 기존 변환 결과는 유지
- 원래 작업 환경의 pyxlsb 패키지와 실제 사용자 DB는 변경하지 않음
- 수정 날짜·내용은 테스트용 소스와 동봉 CHANGES.md에 기록

모든 의존성을 새로 내려받은 완전한 클린 환경 테스트는 아닙니다.

## 발견 후 수정한 사항

1. 시트 시작 열이 큰 경우 너비만으로는 실제 할당되는 열 수를 제한하지 못했습니다.
   시작 위치를 포함한 끝 행·끝 열 위치를 검사하도록 보완하고 실제 BIFF 입력으로 검증했습니다.
2. system-site-packages 가상환경에서 시스템 pyxlsb가 나중에 열거되면 환경 기록에
   수정본 대신 시스템 버전이 남을 수 있었습니다. importlib의 우선 적용 버전을 기록하도록
   수정하고 재빌드하여 `1.0.10+heartwings.validation`이 실행 결과와 일치함을 확인했습니다.

## 검증 산출물

로컬 작업 결과이며 Git에는 배포 바이너리·로그를 넣지 않습니다.

- `build/validation/frozen-check-final.json`: frozen 데이터·고지 검증
- `build/validation/installed-check.json`: ZIP 재배치 후 검증
- `build/validation/release-check-final.json`: 소스·실행 파일 대응 검사
- `build/validation/stage5-build-final.log`: 수정본 빌드 로그
- `dist/validation-macos/`: 검증용 수정본, 대응 소스 ZIP, 릴리스 JSON

이 폴더의 앱은 **검증용 수정본**이며 정식 배포본이 아닙니다. 외부 게시하지 않았습니다.

이 보고서 자체를 포함하지 않습니다.

## 미검증 / 릴리스 전 남은 확인

- Windows·Linux: 해당 OS 실행 환경이 없어 빌드·설치·실행을 검증하지 않았습니다.
- GUI 조작: Computer Use에 사용 가능한 브라우저·앱이 없고 native pipe 연결이 실패하여
  실제 화면에서 XLSB 업로드, 프로그램 정보 확장 및 다운로드 버튼 클릭을 검증하지 못했습니다.
  버튼 콜백은 자동 테스트로 확인했고 frozen 리소스 읽기는 실제 실행 파일로 확인했습니다.
- macOS 네이티브 창 조작, 다운로드 파일 저장 대화상자, Gatekeeper/공증 배포 흐름은 미검증입니다.
- 실제 Excel에서 생성한 다양한 XLSB와 1904 날짜 체계는 미검증입니다.
- 일반 의존성을 완전히 새로 설치하는 환경 및 OS별 네이티브 패키지 재현은 추가 확인이 필요합니다.

재검증 명령과 OS별 실행 파일 경로는 루트 `BUILDING.md`를 참고하세요.
