    통계·내보내기

    실적을 확인할 기간과 기록 상태를 정하고, 필요한 형식으로 자료를 내보내세요.

    기간별 상담 통계 확인하기

    메뉴 위치 통계

    1. 확인할 시작일과 종료일 또는 제공되는 기간 선택 항목을 지정합니다.
    2. 완료 상담의 학생 수·시간과 유형별 현황을 확인합니다.
    3. 월별·학년별·상담 분야별 결과를 살펴봅니다. 분야별 표시에서는 상담 유형을 선택해 확인합니다.
    4. 예상한 수치와 다르면 원본 일지의 일시·상태·집단 출석을 확인합니다.

    종료일을 포함한 한국 시간 기준으로 집계합니다. 유형·월·학년·분야는 완료 일지 기준이며 심리검사·교육/행사는 등록 건을 집계합니다. 학년은 현재 학생 정보 기준이고, 집단상담은 출석 학생의 학년별로 회기당 1건을 집계합니다.

    상담 기록 PDF 만들기

    메뉴 위치 학생 상세의 PDF 또는 설정 → 내보내기

    1. 학생별 자료는 학생 상세의 ‘PDF’를, 전체 자료는 ‘설정 → 내보내기’의 ‘모든 일지 PDF 내보내기’를 선택합니다.
    2. 전체 내보내기에서는 학년도 또는 직접 입력한 기간과 일지 상태를 확인합니다.
    3. 출력 화면의 옵션을 확인하고 ‘PDF 생성 및 다운로드’를 누릅니다.
    4. 내려받은 PDF를 열어 대상·기간·내용을 확인한 뒤 사용합니다.

    PDF는 읽고 출력하기 위한 자료입니다. 새 컴퓨터에서 기록을 계속 편집하려면 PDF가 아니라 DB 백업 파일을 준비하세요.

    NEIS 업로드용 XLSX 만들기

    메뉴 위치 설정 → 내보내기 → NEIS 업로드용 파일 내보내기

    1. ‘내보낼 기간’을 학년도 또는 ‘기간 직접 입력’으로 선택합니다. 학년도는 3월 1일부터 다음 해 2월 말일까지입니다.
    2. ‘내보낼 일지 상태’를 ‘완료만’ 또는 ‘완료 및 예약’ 중에서 선택합니다.
    3. ‘일지 XLSX 만들기’를 누르고 생성된 전체 건수와 확인이 필요한 행을 검토합니다.
    4. ‘XLSX 다운로드’를 눌러 저장합니다.
    5. 엑셀에서 누락이나 확인이 필요한 항목을 점검한 뒤 기관의 NEIS 업로드 절차에 따라 사용합니다.

    이 기능은 업로드용 파일을 생성합니다. 마음나래에서 NEIS로 기록을 직접 전송하는 기능은 아닙니다. 기간이나 상태를 바꾸면 파일을 다시 만들어야 합니다.

    내부결재용 상담 대장 만들기

    메뉴 위치 설정 → 내보내기 → 내부결재용 상담 대장 내보내기

    1. 기간과 일지 상태를 선택한 뒤 ‘상담 대장·학생 정보 만들기’를 누릅니다.
    2. 상담 건수와 연결 학생 수, 확인이 필요한 항목을 검토합니다.
    3. ‘내부결재용 상담 대장 내보내기’로 상담 대장을 내려받습니다.
    4. 필요한 경우 ‘Wee클래스 보관용 학생 정보 대장 내보내기’로 연결 학생 정보 파일을 따로 내려받습니다.
    5. 파일의 대상과 내용을 확인해 용도에 맞게 보관·사용합니다.

    상담 대장과 학생 정보 파일은 서로 역할이 다릅니다. 필요한 파일을 각각 내려받았는지 확인하세요.
