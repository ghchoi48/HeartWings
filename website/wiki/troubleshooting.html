    문제 해결

    어느 단계에서 문제가 생겼는지 확인하고, 아래 순서대로 점검하세요.

    DB가 열리지 않거나 복원이 실패해요

    • 현재 DB를 여는 비밀번호와 백업 파일 비밀번호를 구분합니다. 비밀번호 변경 전에 만든 백업에는 이전 비밀번호가 필요합니다.
    • 전체 DB 복원 뒤에는 백업 당시 비밀번호, 부분 복원 뒤에는 현재 DB 비밀번호로 다시 엽니다.
    • 선택한 복원 기능과 파일 종류가 일치하는지 확인합니다. PDF·XLSX 내보내기 파일은 DB 복원 파일이 아닙니다.
    • 전체 DB 복원 파일이 256MB 이하인지 확인합니다. 오류가 반복되면 파일을 임의로 수정하지 말고 원본을 보관합니다.

    정확한 복원 순서는 전체 DB 복원과 부분 백업 복원을 참고하세요.

    명부나 첨부파일이 올라가지 않아요

    파일확인할 제한
    학생·교사 명부서식에 맞는 XLSX, 10MB 이하
    기존 상담기록관리 자료XLSB, 10MB 이하
    일지 첨부파일파일당 20MB, 한 번에 10개까지
    전체 DB 복원전체 DB 백업 파일, 256MB 이하

    한 번에 하나의 업로드 요청을 처리하므로 진행 중인 업로드가 끝날 때까지 기다립니다. 명부는 미리보기의 오류 행을 수정해 다시 올리세요. 파일 확장자만 바꾸는 것으로 형식이 변하지는 않습니다.

    새 일지의 첨부가 사라졌다면 일지를 저장했는지 확인합니다. 작성 취소 시 임시 첨부파일은 폐기됩니다.

    연결한 일정이 보이지 않아요

    1. 확인하는 날짜 범위가 맞는지, ‘캘린더 목록’에서 해당 캘린더가 체크되어 있는지 확인합니다.
    2. NEIS는 ‘설정 → 일반’의 인증키·교육청·학교 코드를 확인합니다. 학사일정은 기본적으로 표시가 꺼져 있습니다.
    3. Google은 캘린더를 보는 웹페이지 주소가 아니라 ‘iCal 형식의 비공개 주소’를 넣었는지 확인합니다.
    4. 인터넷 연결을 확인하고 새로고침합니다. Google에서 비공개 주소를 재설정했다면 앱의 연결 주소도 수정합니다.

    Google 일정과 NEIS 학사일정은 읽기 전용입니다. 변경은 원본 서비스에서 진행합니다. 일정 관리 안내에서 연결 절차를 확인하세요.

    통계나 내보내기 건수가 예상과 달라요

    1. 시작일·종료일과 학년도를 확인합니다. 학년도 기간은 달력의 1월부터 12월까지와 다릅니다.
    2. 완료 상태인지 확인합니다. 내보내기는 선택에 따라 예약을 포함할 수 있습니다.
    3. 집단 상담의 출석과 학생의 현재 학년 정보를 확인합니다.
    4. 설정이나 기록을 바꾼 뒤에는 내보내기 파일을 다시 생성합니다.
    5. 생성 결과의 ‘확인이 필요한 행’을 확인하고 내려받은 파일에서도 해당 항목을 점검합니다.

    집계 기준은 기간별 상담 통계에 설명되어 있습니다.

    업데이트와 다른 컴퓨터 사용

    새 버전은 최신 릴리스에서 확인합니다. 업데이트 전에 DB 백업을 내려받고 릴리스의 변경 사항을 확인하세요. 앱 실행 파일과 사용자 DB는 별도 위치에 저장됩니다.

    컴퓨터를 옮길 때는 기존 컴퓨터에서 전체 DB 백업을 만들고 새 컴퓨터에서 복원합니다. 컴퓨터 이동 절차를 따라 기록을 확인한 뒤 기존 환경을 정리하세요.

    문제가 계속될 때 문의하기

    ‘설정 → 프로그램 정보’에서 버전을 확인하고, 다음 정보를 정리하면 문제를 파악하기 쉽습니다.

    • 사용 중인 운영체제와 마음나래 버전
    • 문제가 발생한 메뉴와 직전에 누른 버튼
    • 오류 메시지의 정확한 내용과 재현 순서
    • 파일 관련 문제라면 확장자와 용량

    이메일로 문의하거나 GitHub에서 문제를 제보할 수 있습니다. 학생 정보·상담 내용·비밀번호·비공개 캘린더 주소는 지우고, 화면이 필요하면 가상 데이터로 재현해 주세요.
