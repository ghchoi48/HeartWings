    시작하기

    앱을 설치하고 학교 정보를 준비한 뒤, 첫 상담 기록을 남겨 보세요.

    앱 설치하기

    최신 릴리스에서 자신의 운영체제에 맞는 설치 파일을 선택합니다. 릴리스에 첨부된 파일과 변경 사항을 함께 확인하세요.

    Windows

    1. 이름이 windows-x64-setup.exe로 끝나는 설치 파일을 내려받습니다.
    2. 설치 파일을 실행하고 설치 마법사의 안내를 따릅니다. WebView2 Runtime이 없으면 설치 과정에서 내려받으므로 인터넷 연결이 필요합니다.
    3. 설치된 마음나래를 실행합니다. 최초 실행 시 ‘마음나래 시작 준비’가 나타납니다.

    macOS

    1. Mac의 CPU에 맞는 DMG 파일을 내려받습니다. Apple Silicon과 Intel용 파일은 릴리스에서 구분해 확인합니다.
    2. DMG를 열고 마음나래 앱을 Applications 바로가기로 드래그합니다.
    3. 응용 프로그램 폴더에서 마음나래를 실행합니다.

    소스 실행이나 개발 환경이 필요하면 빌드 안내를 참고하세요.

    비밀번호와 학교 정보 설정하기

    1. DB 비밀번호를 4글자 이상 입력하고 확인란에 같은 값을 입력한 뒤 ‘다음’을 누릅니다.
    2. 교육청과 학교급을 선택하고 학교명을 입력합니다. ‘불러오기’에서 학교를 선택하면 학교 나이스 번호가 저장됩니다.
    3. 상담교사 이름과 필요한 사무실 번호를 입력합니다. 교육청·학교명·상담교사 이름은 필수입니다.
    4. ‘저장하고 다음’을 누릅니다. 나이스 번호와 사무실 번호는 나중에 설정할 수도 있습니다.
    5. 기존 자료가 있으면 ‘울산형 DB 마이그레이션’ 또는 ‘교사·학생 일괄 등록’을 선택합니다. 나중에 등록하려면 ‘건너뛰기’를 선택합니다.

    DB 비밀번호는 기록을 여는 데 필요합니다. 백업 복원에는 현재 비밀번호가 아니라 백업을 만들 당시의 비밀번호가 필요할 수 있습니다.

    첫 상담 기록 남기기

    1. ‘학생 관리’에서 학생을 등록하거나 기존 학생을 선택합니다.
    2. 학생 상세 화면의 ‘상담 일지’를 눌러 일지 관리로 이동합니다.
    3. ‘새 상담 사례’를 만들고 사례명을 입력한 뒤 ‘사례 저장’을 누릅니다.
    4. ‘새 상담 일지’를 눌러 일시·소요 시간·상담 상태와 내용을 입력하고 ‘일지 저장’을 누릅니다.
    5. 저장한 일지를 다시 열어 내용과 대상 학생을 확인합니다. 상담을 마친 기록은 상태가 ‘완료’인지 확인합니다.

    상세한 작성 방법은 개인 상담 작성, 명부 준비는 명부 일괄 등록을 참고하세요.

    하루를 마무리할 때

    1. 홈의 미작성 일지 건수와 캘린더를 살펴보고 작성할 기록이 남아 있는지 확인합니다.
    2. ‘설정 → DB → DB 관리’에서 ‘전체 DB 백업’을 내려받습니다.
    3. 자리를 비울 때는 상단 ‘DB 잠금’을 누릅니다. ‘설정 → 시스템’에서 자동 잠금도 설정할 수 있습니다.

    컴퓨터를 바꾸기 전에는 전체 DB 복원 절차까지 확인하세요.
