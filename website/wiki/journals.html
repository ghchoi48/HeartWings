    상담 일지

    학생과 상담 유형에 맞는 기록을 선택하고, 실제 진행 상태와 내용을 함께 남기세요.

    개인 상담과 상담 사례

    메뉴 위치 학생 관리 → 학생 선택 → 상담 일지

    1. 상담 사례 목록에서 기존 사례를 선택합니다. 새로운 상담 흐름이면 ‘새 상담 사례’를 누르고 사례명을 입력해 ‘사례 저장’으로 저장합니다.
    2. 필요에 따라 ‘접수 면접’, ‘사례 개념화 보고서’, ‘종결 보고서’를 작성합니다. 각 보고서는 선택한 사례와 연결됩니다.
    3. ‘새 상담 일지’를 눌러 상담 일시와 소요 시간을 입력합니다.
    4. 상담 상태·방법·대상·분야를 확인하고 상담 내용을 작성합니다. 필요한 경우 비밀 메모를 별도 입력합니다.
    5. 첨부할 자료가 있으면 저장 전에 추가하고 ‘일지 저장’을 누릅니다.
    6. 일지 목록에서 저장한 기록을 다시 열어 대상·일시·내용을 확인합니다.

    이미 작성한 기록은 일지 목록에서 선택해 수정합니다. 편집 도중 취소하면 ‘계속 작성’ 또는 ‘변경 내용 버리기’로 저장하지 않은 내용의 처리 방법을 선택할 수 있습니다.

    예약과 완료 상태 구분하기

    예정된 상담을 먼저 기록할 때와 상담을 마친 뒤에는 상태를 구분해야 합니다. 상담 후에는 실제 소요 시간과 내용을 확인하고 완료 상태로 저장하세요.

    통계의 상담 유형·월·학년·분야 집계는 완료 일지를 기준으로 합니다. 기록이 통계에 보이지 않으면 날짜뿐 아니라 상태를 확인하세요. 심리검사·교육/행사는 등록 건을 집계합니다.

    캘린더에서 만든 상담 예약도 관련 일지를 열어 이어서 작성할 수 있습니다. 상담 예약 만들기를 참고하세요.

    집단 상담 기록하기

    메뉴 위치 집단 상담

    1. 집단을 선택하거나 새 집단을 만들고 참여 학생을 확인합니다.
    2. 선택한 집단에서 새 회기 일지를 엽니다.
    3. 일시·소요 시간·상담 상태와 회기 내용을 입력합니다.
    4. 참여 학생별 출석과 참여 태도를 확인해 입력합니다. 집단에 속한 학생 모두가 실제 출석한 것으로 처리되지 않도록 점검합니다.
    5. 저장한 회기를 다시 확인합니다. 통계 확인 시에는 출석 학생과 완료 상태도 함께 확인합니다.

    기록 유형별 작성 위치

    유형작성 위치와 확인 사항
    교사 자문‘자문’에서 교사를 선택한 뒤 일지를 작성합니다. 자문 대상과 내용을 확인합니다.
    심리검사학생의 일지 관리에서 ‘심리 검사’ 탭을 선택합니다. 검사 일자와 검사 정보를 기록합니다.
    특별교육‘특별교육’에서 대상 학생과 교육 정보를 선택합니다. 대상·근거 법률 등 해당 항목을 확인합니다.
    교육·행사‘교육/행사’에서 교육이나 행사 기록을 작성합니다. 일자와 참여 관련 정보를 확인합니다.

    유형별로 입력 항목이 다릅니다. 다른 유형에 임의로 기록하기보다 실제 활동에 맞는 화면에서 작성해야 내보내기와 집계에서도 구분됩니다.

    첨부파일과 저장 확인

    1. 일지 편집 화면에서 필요한 첨부파일을 추가합니다. 파일당 20MB, 한 번에 10개까지 업로드할 수 있습니다.
    2. 업로드가 끝난 뒤 파일명을 확인하고 일지를 저장합니다. 새 일지의 첨부파일은 일지를 저장할 때 함께 저장됩니다.
    3. 저장한 일지를 다시 열어 첨부파일을 확인하고 필요하면 미리보기나 다운로드를 이용합니다.

    새 일지 작성을 취소하면 임시 첨부파일도 폐기됩니다. 업로드가 진행 중이면 끝날 때까지 기다린 뒤 다음 파일을 처리하세요. 파일을 선택한 것만으로 일지가 저장되지는 않습니다.

    출력 전에는 PDF 미리보기와 출력 옵션에서 포함할 내용을 확인하세요.
