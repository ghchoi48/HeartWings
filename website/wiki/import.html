    기존 자료 가져오기

    울산형 상담기록관리 XLSB 파일을 검사하고, 연결 대상과 오류를 확인한 뒤 DB에 추가합니다.

    가져오기 전에 준비하기

    메뉴 위치 설정 → DB → 울산형 상담기록관리 DB 가져오기

    1. 현재 마음나래 자료가 있으면 먼저 전체 DB 백업을 내려받습니다.
    2. 원본 XLSB 파일을 Excel에서 열어 수식 계산을 완료하고 저장합니다. 가져오기는 수식 자체를 계산하지 않고 저장된 값을 읽습니다.
    3. 10MB 이하 XLSB 파일 하나를 준비합니다. 일반 학생·교사 XLSX 명부는 일괄 등록에서 처리합니다.
    4. 자료의 학년도와 원본에서 사용한 교시별 시작 시간을 확인합니다.

    인적사항등록·상담대장 자료는 사례번호로 연결하며, 식별 정보가 일치하는 기존 대상이 있으면 연결합니다. 대분류가 자문인 경우 인적사항의 성명은 교사로 등록됩니다.

    파일 검사와 오류 수정

    1. ‘자료의 학년도’를 지정하고 ‘교시별 시작 시간 설정’에서 원본의 시간을 입력합니다.
    2. ‘상담기록관리 XLSB 파일’에 파일을 선택하고 검사 결과를 기다립니다.
    3. 대상별 건수와 오류를 확인합니다. 시작 시각에는 교시별 설정이 적용되며 소요 시간은 원본 시간(시) × 60 + 시간(분)으로 계산합니다.
    4. 오류가 있으면 ‘행 수정 / 일지 지정 / 제외’에서 해당 행을 확인합니다. 값이나 등록할 일지를 수정하고 ‘수정사항 저장 후 다음 오류’를 진행합니다.
    5. 설정을 바꾼 경우 ‘설정 적용 후 다시 검사’를 누릅니다. 제외한 행이 있으면 제외 건수와 대상을 확인합니다.

    검사와 화면에서의 수정만으로 DB에 등록되지는 않습니다. 최종 추가 전에 연결 대상과 제외 행을 확인하세요.

    검사한 자료 추가하고 확인하기

    1. 오류와 등록 대상 검토가 끝나면 ‘검사한 자료를 DB에 추가’를 누릅니다.
    2. 처리 결과를 확인한 뒤 학생 관리와 해당 유형의 일지 화면으로 이동합니다.
    3. 대표 학생 또는 교사를 선택해 상담 일시·유형·내용이 의도한 기록에 연결되었는지 확인합니다.
    4. 통계에서도 이관한 기간을 선택해 기록을 점검하고, 확인을 마친 상태를 다시 백업합니다.

    이미 가져온 자료라는 안내가 나오면 같은 파일을 반복 등록하기 전에 기존 이관 결과를 확인하세요. 원본 자료는 검증이 끝날 때까지 보관합니다.

    가져오기가 멈추거나 거부될 때

    • 파일 확장자가 XLSB인지, 10MB 이하인지 확인합니다. 확장자 이름만 바꾼 파일은 사용할 수 없습니다.
    • 수식 결과가 비어 있다면 Excel에서 계산하고 저장한 파일로 다시 검사합니다.
    • 학년도·날짜·시간·대상 연결 오류는 검사 화면의 구체적인 오류 메시지에 따라 수정합니다.
    • 다른 파일 업로드가 진행 중이면 완료 후 다시 시도합니다.

    계속 실패하면 문의에 필요한 정보를 정리하세요.
