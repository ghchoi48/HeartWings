    일정 관리

    상담 예약, 상담실 일정, 학교 학사일정을 함께 확인하세요.

    월간·주간 일정 살펴보기

    메뉴 위치 캘린더

    1. 월간 또는 주간 보기에서 확인할 기간으로 이동합니다. ‘오늘’을 누르면 현재 날짜로 돌아옵니다.
    2. ‘캘린더 목록’을 열어 표시할 캘린더를 선택합니다.
    3. 일정 항목을 눌러 상세 정보를 확인합니다. 상담 관련 일정은 연결된 기록으로 이동해 내용을 확인합니다.
    4. 일정이 보이지 않으면 날짜 범위와 캘린더 표시 여부를 먼저 확인합니다.

    상담 예약 만들기

    메뉴 위치 캘린더 → 일정 추가

    1. 예약할 날짜를 선택하고 ‘일정 추가’를 누릅니다.
    2. ‘캘린더’에서 상담 일정용 항목을 선택합니다. 사용자 캘린더를 선택하면 일반 일정 입력 항목이 나타납니다.
    3. 상담 종류와 대상, 시작 시각·소요 시간 등 표시된 예약 정보를 입력합니다. 선택할 학생이나 집단이 없으면 먼저 해당 명부를 등록합니다.
    4. ‘일정 저장’을 누르고 캘린더에서 예약이 보이는지 확인합니다.
    5. 상담을 마친 뒤 예약 항목을 열어 실제 일지 내용과 상태를 갱신합니다.

    예정된 상담을 일반 사용자 일정으로만 만들면 상담 일지와 같은 방식으로 집계되지 않습니다. 상담 기록을 이어 작성할 일정은 상담 예약으로 등록하세요.

    상담실 사용자 일정 등록하기

    1. ‘캘린더 목록 → 캘린더 추가’에서 ‘상담실 운영’처럼 알아보기 쉬운 이름과 표시 색상을 지정합니다.
    2. ‘일정 추가’에서 만든 사용자 캘린더를 선택합니다.
    3. 제목과 날짜·시간을 입력합니다. 하루 종일 또는 여러 날 이어지는 일정은 종일 여부와 종료 날짜도 확인합니다.
    4. 필요한 장소와 내용을 입력하고 ‘일정 저장’을 누릅니다.
    5. 수정할 때는 해당 일정을 다시 엽니다.

    사용자 캘린더를 삭제하면 그 안의 일정도 삭제됩니다. 화면에서 잠시 감추려면 캘린더 목록의 표시 선택을 해제하세요.

    NEIS 학사일정 연결하기

    메뉴 위치 설정 → 일반 → 나이스 연동

    1. 학교 정보의 교육청과 학교 나이스 번호를 확인합니다.
    2. NEIS API 인증키를 입력하고 학교 설정을 저장합니다. 인증키 입력란 아래 ‘인증키 용도 및 발급 방법’에서 발급 안내를 확인할 수 있습니다.
    3. ‘캘린더 → 캘린더 목록’에서 ‘학사일정 (NEIS)’을 체크합니다. 처음에는 표시가 꺼져 있습니다.
    4. 조회할 날짜로 이동해 학사일정을 확인하고, 변경된 일정이 있으면 새로고침합니다.

    학사일정은 읽기 전용입니다. 표시 선택은 저장되며 홈 캘린더에서도 확인할 수 있습니다. 인증키는 나이스 교육정보 개방 포털의 인증키 신청에서 준비합니다. 공식 활용 안내도 참고하세요.

    Google 캘린더 연결하기

    메뉴 위치 캘린더 → 캘린더 목록 → 구글 캘린더 연결

    1. 컴퓨터의 Google 캘린더 설정에서 연결할 캘린더를 선택합니다.
    2. ‘캘린더 통합’에서 ‘iCal 형식의 비공개 주소’를 복사합니다. 항목이 없다면 조직의 계정 설정을 확인합니다.
    3. 마음나래에서 ‘구글 캘린더 연결’을 열고 캘린더 이름과 ‘비공개 iCal 주소’를 입력합니다.
    4. ‘연결 확인 후 저장’을 누른 뒤 캘린더 목록에서 표시 여부를 확인합니다.
    5. 일정 수정은 Google 캘린더에서 진행하고 마음나래에서 새로고침해 확인합니다.

    비공개 주소로 일정에 접근할 수 있으므로 다른 사람에게 공유하지 마세요. 마음나래에는 주소와 일정이 암호화된 DB에 저장됩니다.

    마음나래에서 Google 일정은 읽기 전용입니다. 연결을 해제하면 앱의 연결 정보와 저장된 일정 캐시만 삭제하며 Google 원본 일정은 유지합니다. 주소 확인 방법은 Google 공식 도움말을 참고하세요.
