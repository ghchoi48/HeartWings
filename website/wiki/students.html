    학생·교사 관리

    명부를 등록하고 학생의 상담 이력을 이어서 관리하세요. 새 학년도에는 명부를 검토한 뒤 확정합니다.

    학생 한 명 등록하기

    메뉴 위치 학생 관리

    1. 새 학생 등록 화면을 엽니다.
    2. 이름·학년·반을 입력하고 학년도와 학적 상태를 확인합니다. 번호·별명·연락처 등 필요한 정보도 입력합니다.
    3. ‘저장’을 누른 뒤 학생 목록에서 이름을 찾아 선택합니다.
    4. 상세 화면의 학적과 인적사항을 확인합니다. 가족 정보는 ‘가족 정보 수정’에서 별도로 입력하고 저장합니다.

    동명이인은 이름뿐 아니라 학년·반·번호를 함께 확인합니다. 학생 정보를 수정할 때 학년도를 바꾸어 저장하면 해당 학년도의 학적을 추가하거나 수정하며 다른 학년도 이력은 유지합니다.

    학생·교사 명부 일괄 등록하기

    메뉴 위치 설정 → DB → 학생·교사 일괄 등록

    1. 등록할 대상에 맞는 ‘학생 서식 다운로드’ 또는 ‘교사 서식 다운로드’를 누릅니다.
    2. 내려받은 XLSX 서식의 열과 작성 안내를 유지한 채 명부를 입력하고 저장합니다. 파일은 10MB 이하로 준비합니다.
    3. 해당 대상의 XLSX 업로드 항목에 파일 하나를 선택합니다.
    4. 미리보기의 등록 대상 수와 오류를 확인합니다. 미리보기에는 최대 20명이 보이지만 등록하면 전체 대상이 추가됩니다.
    5. 오류가 있으면 원본 파일을 수정한 뒤 다시 업로드합니다. 오류가 없는지 확인한 후 ‘학생 등록’ 또는 ‘교사 등록’을 누릅니다.
    6. 학생 관리 또는 자문의 교사 목록에서 등록된 사람을 확인합니다.

    일괄 등록은 파일의 대상을 새로 추가하는 작업입니다. 새 학년도 기존 명부를 갱신하려면 아래 ‘새 학년도 준비’를 사용하세요.

    학생 이력과 상담 타임라인

    메뉴 위치 학생 관리 → 학생 선택

    1. 목록에서 대상 학생을 찾아 선택합니다.
    2. 학적·연락처·가족 정보를 확인합니다. 잘못된 정보는 해당 수정 화면에서 변경합니다.
    3. ‘상담 타임라인’에서 과거 기록을 확인합니다. 이전 내역이 더 있으면 ‘이력 더 보기’를 누릅니다.
    4. 상담 기록을 이어 작성하려면 ‘상담 일지’를 누릅니다. 자료를 출력하려면 ‘PDF’에서 출력 대상을 확인합니다.

    새 학년도 준비하기

    메뉴 위치 설정 → DB → 새 학년도 준비

    1. 먼저 전체 DB 백업을 만듭니다. 학생 진급과 교사 명부 갱신에 사용할 새 학년도 전체 명단을 준비합니다.
    2. 기준 학년도와 대상 학년도를 확인하고 서식을 내려받아 작성합니다.
    3. 학생 또는 교사 전체 명단 XLSX를 업로드합니다. 명단에 없는 기존 인원도 검토 대상에 포함됩니다.
    4. 최종 확인 화면에서 처리 종류와 변경 전후 정보를 확인합니다. 동일인 연결이 필요한 항목은 이름만으로 판단하지 말고 기존 정보를 함께 확인합니다.
    5. ‘오류 수정’과 동일인 확인 화면에서 미해결 항목을 처리합니다. 변경한 값은 ‘편집 반영’으로 검토 내용에 반영합니다.
    6. 오류·미해결 항목을 모두 처리한 뒤 ‘최종 확정’을 누릅니다.
    7. 학생 관리에서 새 학년도 학적과 기존 상담 이력이 올바르게 연결되었는지 확인합니다.

    검토 내용은 최종 확정 전에는 DB에 저장되지 않습니다. 검토를 취소하거나 화면을 닫기 전에 확정 여부를 확인하세요.

    교사 정보와 자문 연결

    메뉴 위치 자문 → 교사 목록

    교사 명부는 자문 대상을 선택할 때 사용합니다. 교사 한 명을 추가하거나 수정할 때는 자문의 교사 목록을 이용하고, 여러 명을 등록할 때는 ‘설정 → DB’의 교사 일괄 등록을 이용합니다.

    자문 기록을 작성하기 전에 대상 교사를 선택했는지 확인하세요. 새 학년도 교사 명부는 일괄 등록을 반복하기보다 ‘새 학년도 준비’의 교사 명부 갱신으로 검토합니다.
