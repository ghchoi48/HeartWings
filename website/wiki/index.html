    마음나래 사용 설명서

    처음 설치하는 순간부터 한 학년의 기록을 정리할 때까지. 지금 하려는 업무에 맞는 안내를 찾아보세요.

    처음이라면 여기서 시작하세요

    마음나래는 학교 상담 기록을 내 컴퓨터에 보관하는 프로그램입니다. 먼저 학교 정보와 학생 명부를 준비하고, 첫 상담 일지를 작성해 보세요.

    1. 설치하고 학교 정보 설정하기 — 사용할 컴퓨터에 앱을 설치하고 DB 비밀번호를 정합니다.
    2. 학생과 교사 등록하기 — 한 명씩 등록하거나 XLSX 명부를 가져옵니다.
    3. 첫 상담 일지 작성하기 — 학생의 상담 사례를 만들고 일지를 저장합니다.
    4. 백업 파일 보관하기 — 기록을 작성한 뒤 암호화 백업을 내려받습니다.

    업무별로 찾아보기

    • 홈 화면

      위젯을 배치하고 오늘의 일정과 할 일을 확인합니다.

    • 학생·교사 관리

      명부 등록, 학생 이력 확인, 새 학년도 준비를 진행합니다.

    • 상담 일지

      개인·집단 상담부터 자문, 심리검사, 특별교육과 교육·행사를 기록합니다.

    • 일정 관리

      상담 예약과 사용자 일정을 등록하고 외부 일정을 확인합니다.

    • 통계·내보내기

      기간별 실적을 확인하고 PDF와 엑셀 파일을 만듭니다.

    • 기존 자료 가져오기

      울산형 상담기록관리 XLSB 자료를 검사하고 이관합니다.

    • 설정·데이터 관리

      사용 환경, 잠금, 백업과 복원, 인수인계를 관리합니다.

    • 문제 해결

      가져오기, 연결, 저장과 내보내기 문제의 확인 순서를 살펴봅니다.

    이 설명서 활용하기

    왼쪽 문서 목록에서 주제를 선택하고, 문서의 목차에서 필요한 항목으로 이동하세요. 휴대전화에서는 문서 목록과 목차를 펼칠 수 있습니다. 검색창에는 ‘백업’, ‘학년도’, ‘집단 상담’처럼 하려는 업무를 입력하세요.

    검색 결과를 누르면 해당 설명으로 바로 이동합니다. 여러 단어를 입력하면 그 단어가 모두 포함된 항목을 찾습니다. 각 목차 링크의 주소를 복사하면 특정 설명을 다시 열거나 공유할 수 있습니다.

    이 설명서는 앱 사용 안내입니다. 실제 상담 기록을 이 웹사이트에 입력하거나 업로드할 필요가 없습니다.
