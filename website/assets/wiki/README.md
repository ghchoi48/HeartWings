HTML이나 JavaScript 수정, 별도 등록 작업은 필요 없습니다. 파일명의 대소문자를 지켜 주세요.

## 촬영과 확인

- 별도 데모 DB의 **가상 학생·교사·상담 기록**을 사용합니다. 실제 개인정보, 비밀번호, NEIS 인증키, 비공개 iCal 주소를 포함하지 마세요.
- 화면 글씨가 읽히는 PNG를 사용합니다. 이미지는 본문 너비에 맞춰 비율을 유지하고 원본 링크로 확대할 수 있습니다.
- 위키에 미리 작성된 대체 텍스트와 캡션에 맞는 화면을 촬영합니다. 다른 내용을 넣으려면 해당 문서의 `figure` 설명도 수정합니다.
- 파일이 없거나 이미지로 읽을 수 없으면 이미지·캡션·원본 링크 전체가 숨겨집니다. 일부 파일만 추가해도 해당 화면만 표시됩니다.
- 로컬 HTTP 서버에서 문서를 새로고침해 확인합니다. 공개 사이트는 파일을 `main`에 반영하고 GitHub Pages 배포가 끝나면 적용됩니다.
- JavaScript를 끈 환경에서는 스크린샷을 숨깁니다. 설명 본문과 문서 탐색은 그대로 이용할 수 있습니다.
- 이미지가 없는 동안 개발자 도구에 해당 경로의 404가 나타나는 것은 예상된 동작입니다. 누락 이미지를 대신할 빈 파일을 만들 필요는 없습니다.
